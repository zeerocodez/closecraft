# Archive

Historical material kept for reference. **Nothing in this folder is part of the
production build, is deployed, or should be edited for live changes.**

- `prototypes/` — Google Stitch / static HTML mockups that preceded the
  Next.js implementation, plus the Stitch screen export.
- `scripts/` — one-off Python/JS utilities used during the redesign
  (theme application, page scaffolding, copy updates). Kept for provenance.
- `screenshots/` — working screenshots from the redesign period.
- `DSS_Complete_Website_Source/` — the standalone DSS website source snapshot
  that was merged into the main app under `src/app/dss/`.

If something here is needed again, copy it back deliberately — do not build
new work on top of archived files.
