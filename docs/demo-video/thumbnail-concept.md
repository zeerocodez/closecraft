## 2. Color Palette & Typography

* **Background:** Deep Ink Slate (`#070B0E`) with subtle linear grid overlay (opacity 0.08).
* **Primary Headline:** Pure White (`#FFFFFF`), ExtraBold Sans-Serif (Inter / Plus Jakarta Sans), tracking tight.
* **Accent Highlighting:** Electric Emerald (`#10B981` / `#34D399`) for high-intent signals and currency badges.
* **Alert Highlight:** Vivid Crimson (`#EF4444`) on the *"REVENUE LEAK DETECTED"* callout card to create compelling visual tension.
* **Secondary Text:** Light Slate (`#94A3B8`).

## 4. Production Design Instructions for Figma / Photoshop

1. Create a 1920&times;1080 canvas (export scaled to 1280&times;720 for optimal web delivery).
2. Apply a subtle radial gradient at (80%, 30%) with color `#059669` at 15% opacity to illuminate the floating UI cards.
3. Export high-resolution screenshots of `/leads` (Lead Drawer) and `/pipeline` (Revenue Leak Alert) from the `apex-demo` workspace.
4. Apply 16px corner radius and a 1px border (`#1E293B`) to the floating cards with drop shadow (`0 20px 25px -5px rgba(0, 0, 0, 0.7)`).
5. Ensure all text passes WCAG AA contrast standards (> 4.5:1) against the dark background.
